# Sayida Parvin — Academic Portfolio

A responsive, light-theme academic portfolio built with HTML, CSS, and JavaScript.

## Features
- Responsive layout for desktop, tablet, and mobile
- Introduction and academic summary
- Featured project cards
- Skills and education sections
- Contact links
- Mobile navigation menu

## Run locally
1. Download or clone this repository.
2. Open `index.html` in your browser.

No build tools are required.

## Before publishing
- Replace `your.email@example.com` with your email address.
- Replace the generic GitHub and LinkedIn links with your real profile URLs.
- Replace each project repository link with the correct repository URL.
- Confirm that every skill listed reflects your actual experience.
- Add a profile photo if you want one.

## Publish with GitHub Pages
1. Create a GitHub repository named `your-username.github.io` (replace `your-username` with your GitHub username).
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. Your portfolio URL will be `https://your-username.github.io/`.

If you use a normal repository name instead, the published URL will usually be `https://your-username.github.io/repository-name/`.
